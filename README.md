# Preguntazo! · Landing de demostración

Contenido:
- `index.html`: página principal
- `css/styles.css`: estilos (tema claro/oscuro, responsive)
- `js/app.js`: formulario, roles, juego y ranking
- `respuesta-actividad.md`: texto de respuesta a la actividad

Cómo usarla: abre `index.html` en el navegador, o sube la carpeta completa a GitHub Pages o Netlify.
Es una demostración: el correo no se envía ni se guarda. Para recoger registros reales, incrusta un Google Form o conecta un servicio de formularios.
Las fuentes se cargan desde Google Fonts; sin conexión se usan fuentes del sistema.
